<h1 align="center"><img src="https://github.com/KrishBharadwaj5678/OmniExplore/raw/main/assets/icons/omni.png" width="35"/> Omni Explore</h1>

<p align="center">
 OmniExplore enables seamless discovery across any topic with comprehensive summaries in your preferred language.
</p>

## <img src="https://github.com/KrishBharadwaj5678/OmniExplore/raw/main/assets/readme/features.gif" width="35"/> Features

| **Feature**                    | **Description**                                                           |
| ------------------------------ | ------------------------------------------------------------------------- |
| 🌐 **Endless Topics**          | Input any subject for detailed summaries.                                 |
| 🌍 **Multiple Languages**      | Specify your preferred language for summaries.                            |
| 🖼️ **Topic Related Images**    |  Displays images to help visualize the topic.                             |
| 📚 **Comprehensive Summaries** | Covers everything from simple concepts to complex ideas.                  |

## <img src="https://github.com/KrishBharadwaj5678/OmniExplore/raw/main/assets/readme/gettingStarted.gif" width="35"/> Getting Started

### 1️⃣ Clone the repository

```bash
git clone https://github.com/KrishBharadwaj5678/OmniExplore.git
```

### 2️⃣ Navigate to project directory

```bash
cd OmniExplore
```

### 3️⃣ Install dependencies

```bash
pip install -r requirements.txt
```

### 4️⃣ Run the App

```bash
streamlit run app.py
```
