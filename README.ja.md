<h1 align="center"><img src="https://github.com/KrishBharadwaj5678/OmniExplore/raw/main/assets/icons/omni.png" width="35"/> Omni Explore</h1>

<p align="center">
 OmniExploreは、あらゆるトピックをシームレスに探索し、お好みの言語で包括的な概要を提供します。
</p>

## <img src="https://github.com/KrishBharadwaj5678/OmniExplore/raw/main/assets/readme/features.gif" width="35"/> 機能

| **機能** | **説明** |
| ------------------------------ | ------------------------------------------------------------------------- |
| 🌐 **無限のトピック** | あらゆるテーマを入力して、詳細な概要を取得できます。 |
| 🌍 **多言語対応** | 概要を表示するお好みの言語を指定できます。 |
| 🖼️ **トピック関連画像** | トピックを視覚的に理解するための関連画像を表示します。 |
| 📚 **包括的な概要** | 簡単な概念から複雑なアイデアまで幅広くカバーします。 |

## <img src="https://github.com/KrishBharadwaj5678/OmniExplore/raw/main/assets/readme/gettingStarted.gif" width="35"/> はじめに

### 1️⃣ リポジトリをクローンする

```bash
git clone https://github.com/KrishBharadwaj5678/OmniExplore.git
```

### 2️⃣ プロジェクトディレクトリへ移動する

```bash
cd OmniExplore
```

### 3️⃣ 依存関係をインストールする

```bash
pip install -r requirements.txt
```

### 4️⃣ アプリを起動する

```bash
streamlit run app.py
```
