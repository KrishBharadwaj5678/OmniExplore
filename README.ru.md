<h1 align="center"><img src="https://github.com/KrishBharadwaj5678/OmniExplore/raw/main/assets/icons/omni.png" width="35"/> Omni Explore</h1>

<p align="center">
  OmniExplore обеспечивает удобный поиск и изучение информации по любой теме, предоставляя подробные сводки на выбранном вами языке.
</p>

## <img src="https://github.com/KrishBharadwaj5678/OmniExplore/raw/main/assets/readme/features.gif" width="35"/> Возможности

| **Возможность** | **Описание** |
| ---------------- | ------------ |
| 🌐 **Неограниченное количество тем** | Введите любую тему и получите подробную сводку. |
| 🌍 **Несколько языков** | Укажите предпочитаемый язык для получения сводок. |
| 🖼️ **Изображения по теме** | Отображает изображения, помогающие визуализировать выбранную тему. |
| 📚 **Подробные сводки** | Охватывает всё — от простых понятий до сложных идей. |

## <img src="https://github.com/KrishBharadwaj5678/OmniExplore/raw/main/assets/readme/gettingStarted.gif" width="35"/> Начало работы

### 1️⃣ Клонирование репозитория

```bash
git clone https://github.com/KrishBharadwaj5678/OmniExplore.git
```

### 2️⃣ Переход в директорию проекта

```bash
cd OmniExplore
```

### 3️⃣ Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4️⃣ Запуск приложения

```bash
streamlit run app.py
```
