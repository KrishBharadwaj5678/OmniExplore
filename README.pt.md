<h1 align="center">
  <img src="https://github.com/KrishBharadwaj5678/OmniExplore/raw/main/assets/icons/omni.png" width="35"/>
  Omni Explore
</h1>

<p align="center">
  O OmniExplore permite descobrir facilmente informações sobre qualquer tópico,
  oferecendo resumos abrangentes no idioma de sua preferência.
</p>

## <img src="https://github.com/KrishBharadwaj5678/OmniExplore/raw/main/assets/readme/features.gif" width="35"/> Recursos

| **Recurso** | **Descrição** |
| ------------------------------ | ------------------------------------------------------------------------- |
| 🌐 **Tópicos Ilimitados** | Insira qualquer assunto para obter resumos detalhados. |
| 🌍 **Múltiplos Idiomas** | Especifique o idioma de sua preferência para os resumos. |
| 🖼️ **Imagens Relacionadas ao Tópico** | Exibe imagens para ajudar a visualizar o tópico. |
| 📚 **Resumos Abrangentes** | Abrange desde conceitos simples até ideias complexas. |

## <img src="https://github.com/KrishBharadwaj5678/OmniExplore/raw/main/assets/readme/gettingStarted.gif" width="35"/> Como Começar

### 1️⃣ Clone o repositório

```bash
git clone https://github.com/KrishBharadwaj5678/OmniExplore.git
````

### 2️⃣ Acesse o diretório do projeto

```bash
cd OmniExplore
```

### 3️⃣ Instale as dependências

```bash
pip install -r requirements.txt
```

### 4️⃣ Execute a aplicação

```bash
streamlit run app.py
```
